MISSION-05 · SAFETRAQ Research & ML Pipeline
SafeTraq — Crash Detection ML Pipeline

Developed the machine learning pipeline for SafeTraq, a smartphone-sensor-based vehicle crash detection system. The project covers sensor data preprocessing, time-series windowing, leakage-safe dataset splitting, model comparison, and evaluation on real driving sessions. A key focus was investigating the gap between simulated test performance and real-world driving behavior, especially false alarms caused by road conditions such as speed bumps and potholes.
